## Retrieval procedure

Start with the DOI or official NASA record. Confirm the title, published author order, year, and version. Use a publisher PDF, an authorized repository manuscript, a library subscription, or an author-permitted copy. When no identifier has been verified, the individual page supplies exact-title and report-number search instructions rather than a guessed link. Keep each downloaded file's attribution and license.
