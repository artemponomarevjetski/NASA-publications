# NASA Publications

This repository collects my **publicly shareable** publications, posters, and technical reports produced with (or directly related to) my work in the **NASA Johnson Space Center Space Radiation Group (2004–2019)**.

Even after I left NASA, several models and analysis pipelines I helped develop continued to be used and extended. Where possible, I also track **follow‑on publications and presentations by former teammates** that build on that work.

## Contents

- **Peer‑reviewed papers** (journal articles, conference proceedings)
- **NASA technical reports** (only when publicly releasable)
- **Posters & presentations**
- **Related software / patents / tech briefs** (citations and public references)
